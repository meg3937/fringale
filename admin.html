Pour changer la carte, les prix, la tournée, les congés, la pizza du moment, l’annonce, les photos de la galerie ou les avis :

Modifier le site

Connecte-toi, choisis « fringale », modifie, puis clique sur Enregistrer (Save). Le site se met à jour tout seul en une à deux minutes.

Les cas les plus courants

Partir en congés

Menu Congés → Ajouter → date de début, date de fin, petit message. Le site affiche « En congés jusqu’au… » et le jour du retour, tout seul.

Changer la pizza du moment

Menu Infos et annonce → Pizza du moment : nom, ingrédients, prix, photo. Laisser le nom vide pour l’enlever.

Afficher une annonce

Menu Infos et annonce → Annonce (par exemple « Fermé exceptionnellement ce samedi »). Elle s’affiche en haut de toutes les pages. Vider le champ pour l’enlever.

Modifier un prix ou une pizza

Menu La carte → cliquer sur la pizza → changer ce qu’il faut. On peut aussi ajouter une pizza, en supprimer une, ou ajouter sa photo.

Ajouter des photos

Menu Galerie → Ajouter → choisir la photo depuis le téléphone, mettre une légende si on veut.

Changer un emplacement

Menu La tournée → modifier le jour, la ville ou le lieu.
